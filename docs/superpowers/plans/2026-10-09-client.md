# TTS client implementation plan

> For agentic workers: use superpowers:executing-plans to execute this plan.

Goal: deliver a lightweight, importable synchronous/asynchronous HTTP client.
Architecture: shared typed contracts and parsing, explicit sync/async transports, job handles independent of connection lifetime. MCP stays on the server.
Tech stack: Python >=3.10, HTTPX, Pydantic 2, pytest, uv, Hatchling.
Spec: https://github.com/lambdawalker/design.ai/tree/main/tts (baseline 0678d14f47f42d9de1ec8dd379cd810f35b32e73).

## Global constraints

Preserve caller content. No tag stripping/translation, no GPU dependencies, no automatic submission retries, no implicit cancellation. Same sync/async operation coverage. Unknown request fields fail; additive response metadata survives. Credentials never follow server-supplied URLs.

## Review focus

- Dropped submission responses must not duplicate work: assert one POST after a transport error.
- SSE replay/partial frames: reconnect with last dispatched ID; do not emit partial frames.
- Existing output file during failed transfer: use atomic replacement and assert original survives.
- Model defaults changing under cached guidance: conditional revalidation on every discovery call.
- Malicious IDs/redirects: reject traversal and never follow redirects or response URLs.

## Tasks

1. Contracts and transport: tests/test_client.py; src/tts_api_client/models.py, errors.py, _common.py. Test exact Unicode/whitespace/tag payload preservation, strict request fields, structured errors, profiles/guidance, compatible API majors, and discovery cache. Run tests RED before implementation, GREEN afterward.
2. Operations and jobs: client.py, async_client.py, jobs.py. Expose all documented endpoints, return typed Job handles, support wait/get/cancel. Test sync/async parity, timeout, terminal errors and cancellation without implicit cancellation. All generation methods accept idempotency_key and never auto-retry.
3. Streaming: _sse.py and client transport methods. events(job_id, reconnect_attempts=3, polling_fallback=True) yields typed events, resumes by Last-Event-ID, then falls back to polling. HTTP assets stream through a temporary destination file. Test replay, disconnect, heartbeat, invalid streams, interrupted transfers, multipart uploads and cleanup.
4. Delivery: README, docs/contracts.md, AGENTS.md, examples, CI and package metadata. Run full tests, lint/format, build wheel/sdist, inspect dependency/import boundaries, perform fresh review, then publish verified source to the requested repository. No PyPI release is implied.

## Contract decisions

The design's collection envelopes and SSE event payloads are not finalized. This SDK accepts bare collections or named models/voices arrays (and data arrays); preserves arbitrary SSE data; polls status to determine terminal state rather than requiring an event name. Document these choices as server integration expectations. Metadata cache revalidates via ETag; without ETag it refetches. Base URL is read-only: use a new client for a new deployment.

## Execution record

- Implemented all four tasks and documented the draft contract choices.
- Tests observed failing before contract/streaming implementation; final suite: 33 passed.
- Real loopback HTTP fixture exercises both sync and async generation, multipart uploads, polling, and downloads.
- Fresh independent review found a transient outage in the SSE status probe bypassing reconnect attempts. Added failing sync/async regression tests, fixed recovery, and verified the full suite. Retryable service-unavailable errors are included; authentication errors are not hidden.
- Ruff check/format, wheel/sdist build, and Twine metadata checks pass. Isolated wheel import verified runtime dependencies are only HTTPX/Pydantic and no GPU/MCP modules load.
- Decisions: immutable base URL for credential/cache isolation; named or bare collection envelopes; raw JSON/text event data with status polling; no PyPI publishing. Documented sync wait deadline and asyncio local-disk-I/O limits. No live unified TTS deployment or GPU inference was tested.
